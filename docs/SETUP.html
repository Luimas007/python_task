Setting this up on your PC

Samsung Phone Query & Review System — a multi-agent assistant answering only from PostgreSQL.

Pick your operating system and environment manager below. The page then shows only the commands that apply to you — every one with a copy button. Nothing here assumes you have seen this project before.

System
Environment

0 Install these four things

Everything else in this guide assumes they are present.

SoftwareVersionCheckDownload
Python3.10 or 3.11python --version python.org — or skip it, Anaconda includes Python
PostgreSQL14+psql --version postgresql.org
Ollamaanyollama --version ollama.com
Gitanygit --version git-scm.com
Windows: tick “Add Python to PATH” in the Python installer, and write down the password you choose for the postgres user during the PostgreSQL install — you need it in step 5.
Anaconda users: you do not need the Python download at all. Anaconda brings its own.

You need about 6 GB of disk (PyTorch ~2 GB, the language model ~2 GB) and 8 GB of RAM. A GPU is optional — everything runs on CPU.

1 Get the code

git clone <this-repo-url> py_task
cd py_task

No Git? Download the ZIP, extract it, and open a terminal in that folder.

Check data/pages/ holds about 30 .html files. These are saved GSMArena pages. GSMArena blocks unfamiliar IP addresses, so on most machines these files are the data source — without them there is nothing to build a knowledge base from.

2 Create the environment

Open Anaconda Prompt from the Start menu — not PowerShell, which does not know conda until you initialise it.

conda create -n samsung_phone_system python=3.10 -y
conda activate samsung_phone_system

PowerShell

python -m venv .venv
.\.venv\Scripts\Activate.ps1
“running scripts is disabled on this system”

Run this once, then activate again:

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Or sidestep it with the classic Command Prompt: .venv\Scripts\activate.bat

python3 -m venv .venv
source .venv/bin/activate
You are inside the environment when your prompt starts with (samsung_phone_system)(.venv). Every command from here on assumes that.

3 Install the Python packages

Windows wheels are CPU-only already, so this is a single command.

python -m pip install --upgrade pip
pip install -r requirements.txt

Install PyTorch from the CPU index first — otherwise pip pulls 2.5 GB of CUDA libraries this project never uses.

python -m pip install --upgrade pip
pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt

The slow step — 5 to 10 minutes.

4 Start PostgreSQL

The installer registered a service. Confirm it is running:

Get-Service -Name postgresql*

If Status says Stopped:

Start-Service postgresql-x64-18

Debian / Ubuntu

sudo apt install -y postgresql
sudo systemctl enable --now postgresql
sudo -u postgres psql -c "ALTER USER postgres PASSWORD 'postgres';"

macOS (Homebrew)

brew install postgresql@16
brew services start postgresql@16

You never create the database by hand — step 6 does it. The postgres role only needs CREATEDB, which it has by default.

5 Write your .env

Copy the template, then put your real PostgreSQL password into it.

Copy-Item .env.example .env
notepad .env
cp .env.example .env
nano .env

One line matters. Set PG_PASSWORD to the password from step 4, then save:

PG_PASSWORD=your_password_here

Every other setting already has a working default. .env is gitignored, so your password never leaves your machine.

6 Create the database tables

python -m scripts.setup_db

You should see:

INFO | database CREATED
INFO | connected: PostgreSQL 18.6 (localhost:5432/samsung_kb)
INFO |   table phones               23 columns
INFO |   table specifications        8 columns
INFO |   cosine_similarity(self) = 1.0000 (expect 1.0)
INFO | setup_db complete

Safe to re-run — it is idempotent.

7 Download the language model

ollama pull llama3.2:3b

About 2 GB. If Ollama did not start on its own, leave this running in its own terminal:

ollama serve
You may skip this entirely. Without Ollama the app still starts and still answers from PostgreSQL — you get spec tables and rankings instead of prose, and the header reads degraded. Nothing is ever invented either way.

8 Run it

python app.py

The first run finds an empty knowledge base, fills it from data/pages/, then opens your browser.

[1/4] PostgreSQL       PostgreSQL 18.6, connected to localhost:5432/samsung_kb
[2/4] local LLM        llama3.2:3b ready
[3/4] knowledge base   10 phones, 237 chunks, 237 embedded
[4/4] embedding model  all-MiniLM-L6-v2 (384-dim, cpu)

ready in 11.0s
  console   http://127.0.0.1:8000
  API docs  http://127.0.0.1:8000/docs-ui

Ask it “Which Samsung phone has the best battery life?” and watch the agents work.

✓ Did it work?

python app.py --check

Checks every dependency and exits. Run this first whenever something is wrong — it names the broken piece instead of making you guess.

python -m scripts.report
python -m scripts.db_browser
pytest -q

A coverage summary, the raw tables in a browser, and the full test suite.
